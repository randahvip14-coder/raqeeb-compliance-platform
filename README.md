# رقيب — المراقب الذكي للامتثال التجاري

منصة ذكية تخدم التجار وأصحاب المنشآت الصغيرة والمتوسطة في متابعة التزاماتهم التنظيمية؛ تحدد المتطلبات المرتبطة بالنشاط والمدينة وحجم المنشأة، وتتابع المواعيد وتحديثات الجهات المختصة وتنبه التاجر استباقياً، مع توضيح أثر التحديثات وذكر المصادر والإحالة للمراجعة القانونية عند عدم اليقين.

## المسار والتحدي
- **المسار الثالث:** الحوكمة والامتثال التجاري الذكي
- **التحدي:** المراقب الذكي للامتثال التنظيمي

## محتوى النموذج الأولي
- **لوحة الامتثال:** مؤشرات توضيحية للدرجة وأقرب استحقاق وتنبيه استباقي.
- **إدخال النشاط والملف:** سيناريو تجريبي (مطعم أو متجر إلكتروني في مكة المكرمة) وتحديث بيانات المنشأة.
- **المتطلبات والمواعيد:** قائمة مرتبة حسب الأولوية مع توضيح المرجع.
- **المستشار الذكي:** أسئلة تجريبية مع توضيح الإحالة للمراجعة القانونية عند الحاجة.
